Native File Dialog Extended 1.3.0
https://github.com/btzy/nativefiledialog-extended

Windows binaries: upstream v1.3.0, commit fc168e8605bfa51aaec22ab0c4e46b9de665a437.
Built with Visual Studio 2022, the static MSVC runtime, and
NFD_OVERRIDE_RECENT_WITH_DEFAULT=ON so supplied starting folders take precedence.

To rebuild from the upstream checkout, run for x64 and Win32 respectively:
cmake -S . -B build-x64 -G "Visual Studio 17 2022" -A x64 -DBUILD_SHARED_LIBS=ON -DNFD_BUILD_TESTS=OFF -DNFD_BUILD_SDL2_TESTS=OFF -DNFD_INSTALL=OFF -DNFD_OVERRIDE_RECENT_WITH_DEFAULT=ON -DCMAKE_POLICY_DEFAULT_CMP0091=NEW -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded
cmake --build build-x64 --config Release
cmake -S . -B build-x86 -G "Visual Studio 17 2022" -A Win32 -DBUILD_SHARED_LIBS=ON -DNFD_BUILD_TESTS=OFF -DNFD_BUILD_SDL2_TESTS=OFF -DNFD_INSTALL=OFF -DNFD_OVERRIDE_RECENT_WITH_DEFAULT=ON -DCMAKE_POLICY_DEFAULT_CMP0091=NEW -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded
cmake --build build-x86 --config Release
Copy each build's src/Release/nfd.dll into the matching win-x64 or win-x86 folder.

Windows ARM64 binary (win-arm64): the same upstream v1.3.0 commit, built with LLVM-MinGW
(clang 23.1.4, aarch64-w64-mingw32, UCRT) with the C++ runtime linked statically and the same
NFD_OVERRIDE_RECENT_WITH_DEFAULT behavior. To rebuild from the upstream checkout:
aarch64-w64-mingw32-clang++ -shared -O2 -DNDEBUG -DNFD_EXPORT -DNFD_OVERRIDE_RECENT_WITH_DEFAULT -fno-exceptions -fno-rtti -std=c++11 -I src/include src/nfd_win.cpp -o nfd.dll -static -lole32 -luuid -lshell32 -Wl,--strip-all
Copy nfd.dll into the win-arm64 folder.
